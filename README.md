# Melo & Melo — Arquitetura dos Sonhos

Site conceitual responsivo para a Melo & Melo Consultoria Imobiliária, com catálogo local, páginas institucionais e narrativa controlada por scroll.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

O projeto usa Vite, React, TypeScript, Tailwind CSS, GSAP, ScrollTrigger e Lenis. O deploy na Vercel usa as configurações padrão de projetos Vite.
